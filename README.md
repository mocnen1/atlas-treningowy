# Atlas Treningowy – aplikacja na telefon

Zapis treningu na siłowni (iPhone, działa bez internetu po instalacji). Część projektu Atlas Treningowy; treningi przesyłane są kodami QR do aplikacji na Windows. Dane treningowe nie trafiają do tego repozytorium.

Instalacja: otwórz https://mocnen1.github.io/atlas-treningowy/ w Safari → Udostępnij → Do ekranu początkowego.
